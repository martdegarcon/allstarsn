# All Stars NN — концепт нового сайта

Кликабельный прототип нового сайта концертной компании [All Stars NN](https://allstarsnn.com) (Нижний Новгород, Казань).
Статический сайт без сборки: HTML + CSS + чистый JavaScript, маршрутизация на hash-ссылках (`#/afisha`, `#/event/tango` и т. д.).

## Запуск

Откройте `index.html` в браузере — сервер не обязателен.

Или локальный сервер:

```bash
npx serve .
# либо
python3 -m http.server 8080
```

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
Файл `.nojekyll` уже лежит в корне.

## Структура

```
index.html            — каркас: шапка, меню, подвал, модальные окна
assets/css/style.css  — все стили (адаптив 320–1440+)
assets/js/app.js      — данные, роутер и все страницы
assets/favicon.svg
```

## Страницы

| Маршрут | Страница |
|---|---|
| `#/` | Главная: баннер-слайдер, афиша (7 событий + карточка «Вся афиша»), новости, подписка, фотоотчёты, блок для артистов |

## Функциональность

- Выбор города в шапке (Нижний Новгород / Казань) — меняет афишу, баннер и меню; запоминается.
- Выпадающие меню «Афиша / Зрителям / Организаторам»; на мобильных — бургер-меню.
- Слайдер с автолистанием (5 с), паузой при наведении и свайпом.
- Поп-ап подписки со скидкой 5% через 3 секунды (показывается один раз).
- Во всех формах — обязательные чекбоксы согласия со ссылками на документы.

## Где править данные

Всё в начале `assets/js/app.js`:

- `EV` — события афиши (город, дата, площадка, цена, описание, картинки);
- `REPORTS` — фотоотчёты;
- `NEWS` — новости;
- `IMG` — ссылки на изображения;
- `DOCS` — тексты юридических документов.

Пример события:

```js
{id:'new1', city:'nn', img:'jeka', cv:'cv_jeka', t:'Полное название', short:'Короткое название',
 cat:'concert', kind:'Концерт', d:new Date(2027,1,14), time:'19:00',
 place:'МТС Live Холл', venue:'МТС Live Холл', price:1800, desc:'Описание'}
```

`cat`: `concert` | `show` | `kids`. Месяцы в `new Date()` считаются с нуля (`1` — февраль).

## Что это прототип, а не продакшн

- Изображения подгружаются с текущего сайта заказчика (Tilda CDN) — перед запуском перенести в проект и сжать в WebP.
- Кнопки «Купить» показывают уведомление — в продакшне здесь виджет Ticketscloud.
- Формы не отправляют данные — нужен бэкенд или сервис форм.
- Промокод `ALLSTARS5`, рейтинги и часть текстов — демонстрационные; места для контента помечены «Здесь будет…».
- Юридические документы — шаблоны, финальный текст и реквизиты готовит юрист.
- «Сегодня» в прототипе зафиксировано на 26.10.2026 (`TODAY` в `app.js`) — для продакшна заменить на `new Date()`.
